# Chapter 9: Faculty Command Center

## 9.1 Overview
Teaching support module with syllabus creation, lecture building, assignment generation, plagiarism checking, and slide generation.

### Access Path
**All Tools → Faculty CMD** (or click 🎓 icon)

### Tabs: Syllabus · Lectures · Assignments · Plagiarism · Slides

---

## 9.2 Syllabus Builder
Upload DOCX/PDF/TXT/MD or paste text → auto-extract course structure:
- **Subject selector**: Multiple subjects with per-subject state
- **Learning outcomes**: Bloom's taxonomy alignment
- **Weekly schedule**: Auto-generated from topic list
- **Assessment scheme**: Exams, assignments, lab work, participation

---

## 9.3 Lecture Builder
Generate lecture content for each topic:
- **Duration**: 30-120 minutes
- **Level**: Undergraduate / Graduate / PhD
- **Output**: Learning objectives, content sections, key terms, discussion questions
- **Linked to syllabus**: Auto-loads topics from uploaded syllabus

---

## 9.4 Assignment Generator
Create assignments with rubrics:
- **Type**: Problem sets, case studies, literature review, lab report
- **Difficulty**: Easy / Medium / Hard
- **Rubric**: Auto-generated grading criteria
- **Answer key**: Generated for instructor reference

---

## 9.5 Plagiarism Checker
Check text for similarity:
- **Input**: Paste text
- **Output**: Similarity score, status (clean/warning/flagged), highlighted sections
- **Thresholds**: <15% clean, 15-30% warning, >30% flagged

---

## 9.6 Slides Generator
Generate presentation slides for lectures:
- **Style**: Academic, Clinical, Corporate, Minimal
- **Count**: 3-30 slides
- **Linked to lecture**: Auto-generates from lecture content

---

## 9.7 Example: Creating a Medicinal Chemistry Course
1. Click **Syllabus** tab → upload existing syllabus PDF
2. Review extracted topics → add/remove as needed
3. Click **Lectures** tab → generate content for each topic
4. Click **Assignments** tab → create problem sets with rubrics
5. Click **Slides** tab → generate slide decks for each lecture
6. Click **Plagiarism** tab → check student submissions
