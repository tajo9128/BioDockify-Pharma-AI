# Appendix B: Glossary

| Term | Definition |
|------|-----------|
| **ADMET** | Absorption, Distribution, Metabolism, Excretion, Toxicity |
| **AMES** | Bacterial reverse mutation assay for mutagenicity |
| **APC** | Article Processing Charge (for open access publishing) |
| **BBB** | Blood-Brain Barrier |
| **BOILED-Egg** | Brain Or IntestinaL EstimateD permeation model |
| **CNN** | Convolutional Neural Network |
| **CYP450** | Cytochrome P450 enzyme family (drug metabolism) |
| **DOAJ** | Directory of Open Access Journals |
| **DPI** | Dots Per Inch (image resolution) |
| **ECFP4** | Extended-Connectivity Fingerprints (radius 4) |
| **GI** | Gastrointestinal |
| **GNINA** | Graph Neural Network for molecular docking |
| **HBA** | H-bond Acceptors |
| **HBD** | H-bond Donors |
| **hERG** | Human Ether-à-go-go Related Gene (cardiotoxicity) |
| **IC50** | Half-maximal Inhibitory Concentration |
| **LogP** | Partition coefficient (octanol/water) |
| **LogS** | Water solubility (log scale) |
| **MOL2** | Tripos MOL2 molecular format |
| **NCI** | Non-Covalent Interaction |
| **NIH** | National Institutes of Health |
| **PAINS** | Pan-Assay Interference Compounds |
| **PDB** | Protein Data Bank format |
| **PDBQT** | AutoDock format (PDB + charges + atom types) |
| **PLIF** | Protein-Ligand Interaction Fingerprint |
| **pKa** | Acid dissociation constant |
| **QSAR** | Quantitative Structure-Activity Relationship |
| **RMSD** | Root Mean Square Deviation |
| **SDF** | Structure Data File |
| **SMARTS** | SMILES Arbitrary Target Specification |
| **SMILES** | Simplified Molecular-Input Line-Entry System |
| **TPSA** | Topological Polar Surface Area |
| **Vina** | AutoDock Vina molecular docking |
| **Williams Plot** | Leverage vs standardized residuals for applicability domain |
| **WoS** | Web of Science |
