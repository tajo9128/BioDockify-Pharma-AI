### slides_pptx
generate PowerPoint from SVG slides
args: `action` (convert, design), `svg_dir`
optional: `output_name`
example:
~~~json
{
  "thoughts": ["I need to create a presentation."],
  "headline": "Generating PPTX",
  "tool_name": "slides_pptx",
  "tool_args": {
    "action": "convert",
    "svg_dir": "workdir/slides/"
  }
}
~~~
