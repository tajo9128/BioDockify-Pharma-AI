## Regulatory Affairs Tool

**Purpose:** Regulatory affairs tools for eCTD structure, ICH guidelines, stability study planning, bioequivalence reports, and IND/NDA submission checklists.

**When to use:**
- User asks about eCTD/CTD structure
- User needs ICH guideline information
- User wants to plan stability studies
- User needs bioequivalence report generation
- User asks about IND/NDA/ANDA submission requirements

**Actions:**
- `ectd_structure` — Common Technical Document (CTD) structure (ICH M4)
- `ich_guidelines` — ICH guideline navigator (40+ guidelines across Quality/Safety/Clinical)
- `stability_planner` — ICH Q1A/Q1B stability study conditions
- `be_report` — Bioequivalence report generator (90% CI, GMR, FDA/EMA format)
- `ind_nda_checklist` — IND/NDA/ANDA/505(b)(2) submission checklists

**API endpoint:** `POST /api/regulatory_enhanced`
