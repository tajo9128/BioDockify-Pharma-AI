Computing...

Radioligand Saturation Binding → Kd, Bmax

Specific binding = Total − Nonspecific. Returns Kd (affinity), Bmax (density), Scatchard & Hill plots.

Dose-Response Curve (4PL) → EC50 / IC50

4-parameter logistic fit. Use direction to set agonist (EC50) or inhibitor (IC50).

Schild Analysis → pA2, KB, Schild slope

Antagonist potency. Slope ≈ 1 = competitive antagonism.

Black-Leff Operational Model → τ, KA

Separates efficacy (τ) from affinity (KA). Requires observed vs system max.

Selectivity Ratio

Format: Name:Kd, Name:Kd (lower = more potent). Aim for >30× over off-targets.
