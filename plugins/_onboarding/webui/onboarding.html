Local AI Setup

Option A — Ollama (easiest):

  1. Install from ollama.com
  2. Run: ollama pull llama3.1:8b
  3. BioDockify auto-detects it at localhost:11434

Option B — LM Studio:

  1. Install from lmstudio.ai
  2. Download a model → Start the local server
  3. BioDockify connects to localhost:1234
